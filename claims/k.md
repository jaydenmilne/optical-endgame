# Summary

This is a broader, more legal technical complaint about the current 1201 exemption
process. Initially the Library considered broad exemptions for entire classes
of works, but in 2006 decided on a more narrow framework for their convenience. 

This has led to two decades of bickering. This is an argument that the Library's
first interpretation was the correct one.
